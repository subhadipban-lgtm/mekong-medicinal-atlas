# Data dictionary — Mekong Medicinal Plant Atlas

Generated by `scripts/build_dictionary.py` from `scripts/schema.py`; do not edit by hand.
`scripts/qa_checks.py` validates every table below against this schema.

Conventions: UTF-8; ISO 8601 dates; country codes ISO 3166-1 alpha-2 (CN China, TH Thailand, VN Vietnam, LA Laos, KH Cambodia, MM Myanmar); stable identifiers built from species names and worksheet row numbers.

## Darwin Core Archive (`data/dwc/`)

`dwca.zip` contains `meta.xml` (column-to-term mapping), `eml.xml` (dataset metadata) and `occurrence.txt` (the published records). `occurrence.txt` holds the 34 Darwin Core terms listed for `occurrences.csv` and nothing else; the atlas flags are not part of the archive.
