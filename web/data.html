Data catalog

1 · Overview

All static datasets are archived on Zenodo with DOIs. The evidence-engine contract JSON is committed in the repository under data/evidence/contract/ (aggregate metadata only; the website serves no /data/evidence/ endpoint). This page is the catalog: it describes each dataset, its schema, its licence, its version, and how to cite it. 16 datasets are catalogued: 5 deposited and 11 with a DOI pending. This is not a download page; the files live on Zenodo.

3 · Live contract (the living layer)

The evidence engine publishes its integration contract from two live, public bases — the api-service and the public GCS bucket — and the same files are committed in the repository under data/evidence/contract/. The contract is aggregate metadata only (per-taxon publication identifiers, tier counts, network summary counts and status stubs — no abstracts, titles or full text). The website itself serves no /data/evidence/ endpoint (an on-site request returns 404); the curl line targets the live api-service endpoint. The table states each endpoint's real status, its schema version, its row count and the first 16 characters of its SHA-256, so a reader can verify that the copy they download is the one this build describes. species_publications.json carries publication identifiers only and is excluded from future repository syncs.
